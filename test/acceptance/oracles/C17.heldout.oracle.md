## 1. Declared contract (deliberately the other branch)

Admission granularity is **RECORD_ATOMIC_WITH_INCOMPLETE_FLAG**: complete entries that precede a truncation point *may* be admitted, but the incomplete entry must not be, and the bundle's completeness state must read `INCOMPLETE`. Disposition map: truncated → quarantine the incomplete entry and admit the complete ones; absent segment → DEFER; unsupported schema → REFUSE; duplicate entry id with conflicting bytes → QUARANTINE; partial-replication non-observation → REPORT_NOT_OBSERVED.

Running the held-out variant on the other branch is deliberate: it prevents an implementation from passing C17 by hard-coding one granularity and calling the other one out of contract.
